BEATHI STUDIO / BEATSCOPE v0.12.2
================================

1. Extract the whole ZIP.
2. Double-click "Beathi Studio.exe".
3. Your default browser opens the local Studio. Drop in WAV, FLAC, MP3,
   OGG, M4A, AAC, AIFF or Opus audio.

Everything runs on this computer. The window that starts the local service
must remain open while the Studio is in use. Closing it stops the service.

The portable build includes the local analysis engine, Node.js, Playwright
and FFmpeg. It uses Microsoft Edge already present on supported Windows 10/11
systems for movie rendering. If Edge is unavailable, analysis, preview and
timing export still work; the Studio reports movie rendering as unavailable.

Windows may show a SmartScreen warning because this community release is not
code-signed. Verify the SHA-256 file published beside the download if desired.

# 风格配方：`hyper_keshiki`（60fps 清透金属 × 多底板平面设计）

- **推荐管线（Layer 2）**：`Layer-Decoupled`（Blender `film_transparent=True` 导出 `fg_rgba` + 独立底板池）
- **推荐帧率**：`60fps`（丝滑运动 + 2 帧径向甩镜切换）
- **推荐 Lint Profile**：`editorial-kinetic`（允许克制等宽排版与几何标尺，封杀廉价发光贴片）

## 核心美学配方
1. **前景与环境同源**：3D 主体统一采用高纯度液态银铬、烟熏黑曜石镜面、清透冰晶玻璃，世界环境球加载与主底板同源的天空/场景图 + 雕塑感深色反射带，杜绝霓虹撞色。
2. **统一胶片色域底板池**：所有实拍底板（蓝天积云、地平线云海、逆光绿叶、极简建筑通道、画廊白、克莱因蓝）先过统一日系冷银钴色域微调，切换底板零 3D 重渲成本。
3. **跨形态视觉编排（复用 `pipeline/opencv_fx.py`）**：
   - `composite_alpha_backdrop`：带轻微边缘天光包裹（light-wrap）的自然叠加；
   - `ordered_halftone_dot_plate`：有序圆点半调印刷蓝图（克莱因蓝/黑白/朱砂印版）；
   - 非对称 75/25 画册分栏 + 极细等宽参数边注；
   - `radial_whip_zoom_blur` + 横纵交叉像素编织 + 结尾 4% 速度子弹时间零重力悬停定格。
4. **适用题材**：高能电子/日系先锋 MV、金属雕塑 × 实拍天空/建筑/植物底板轮换、极简杂志分栏排版与子弹时间定格。

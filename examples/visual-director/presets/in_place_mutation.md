# 风格配方：`in_place_mutation`（背景锁死 × 局部原位异变 × 双世界物理反射）

- **推荐管线（Layer 2）**：`Layer-Decoupled`（双反射球 3D 透明前景 `fg_sky` / `fg_alt` + 1:1 像素锁死的原位局部异变底板）
- **推荐帧率**：`60fps`（支持 180 BPM 高频表里乒乓闪切或关键重音预告闪帧）
- **推荐 Lint Profile**：`universal-baseline`

## 核心美学配方（治好“高频闪切不自然”的黄金法则）
1. **背景锁死原则（最关键！）**：
   - 当画面在“正常世界 ↔ 异变世界”间高频乒乓切换时，**绝对不要让整个天空/背景明度发生断崖跳变**（例如高亮晴空硬切 `#000000` 死黑棚拍底）；
   - 正确做法：从原底板中用连通域泛洪抠出**无孔局部轮廓遮罩**（如天空中的积云），仅在遮罩内部将局部对象 1:1 原位转译成异变材质（如日照血肉筋膜、绘卷墨云、金属结晶），并提亮暗部、融入原背景环境散射光色，再无缝贴回**像素 100% 不变的原背景**。
   - 正常底板与异变底板必须共用**完全相同的视差平移、缩放公式与色温 LUT**，确保异变瞬间 0 像素位移、0 明度断崖。
2. **双世界物理反射同步**：
   - 用同一份确定性时间轴调度文件同时驱动 Blender 与 OpenCV：仅在异变帧用异变环境球渲染 3D 前景反射，正常帧复用原晴空反射——金属/玻璃雕塑表面会在拍点瞬间与背景异变同步反射新材质光影。
3. **杜绝中途背景乱跳**：
   - 在原位异变段落内，保持外框/侧栏与主背景稳如磐石；其他独立暗调空间（如东方地狱绘卷）安排在专属段落，不随机打断原位异变节奏。
4. **适用题材**：高频踩拍表里世界翻转、大晴天“蓝天不变、云朵原地异变”白昼见鬼 MV、同构图局部材质变异实验片。

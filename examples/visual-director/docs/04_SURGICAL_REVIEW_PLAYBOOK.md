# 04｜导演审片与外科手术修改指南（打通 BeatScope `creative-review.json`）

当技术 LLM 跑出 `probe_grid.png` / `probe_grid_gray.png` 或经 BeatScope `render.mjs --frames-dir` 封片后的成品 MP4 时，导演 LLM 必须严格执行本指南：**锁死优秀段落 + 精确到时间/参数局部动刀，严禁重发全量 Spec 让技术 LLM 从头重写**。

---

## 一、 通用审片五步快诊（适用任何风格）
1. **先定“不可动产”（`locked_intervals`）**：找出成片里质感最对味、节奏最稳的歌曲时间段（使用 target-song 秒数，如 `[16.5, 24.0]`），明确锁死，禁止改动。
2. **反“单一物件换色屏保”多样性核查**：扫一眼多帧 `probe_grid.png`——如果超过 60% 的格子都是同一个物体/同一景别仅换色板滤镜，**必须打回补足形态与景别落差**。
3. **去色测骨与曝光连贯性核查（看 `probe_grid_gray.png` 与成对切帧）**：
   - 去色后主体与背景的黑白层次、主次焦点是否立得住？
   - **跨镜头/高频乒乓切换检查**：如果用户感觉“切过去不协调/生硬”，立刻排查**三大根因**：① **明度断崖**（如高亮晴空硬切死黑棚拍）；② **空间尺度脱节**（如远景天空硬切微距特写）；③ **背景中途乱跳**（同一段戏里背景底板无序跳变）。需要局部异变时，优先锁死不变背景的像素与曝光！
4. **死盯接缝与偷懒反弹**：检查遮罩/透明边缘有无 1px 泛白锯齿或抠图穿孔？前景光影反射是否与背景世界匹配？有没有溜进本项目 Lint Profile 禁用的廉价占位符或未平滑参数？
5. **音画对齐与防抖审查（结合 `verify.mjs` + 带原曲实看）**：
   - 检查 `verify.mjs` 的 `savedStages`、`audioMatch`、`frameWarnings` 与 `declaredEvents` 命中偏移。
   - 检查是否出现无动机高频抖动（把未平滑原始 `bands` 绑进了位置/缩放），或与歌曲呼吸脱节的僵硬机械感。

---

## 二、 外科手术修改单黄金规则（配合 `--reuse-unchanged` 秒级热替换）
- **绝不重发整份大 Spec**：代码 LLM 一旦通读大 Spec 重写，极易把原本做绝的段落顺手改崩。
- **锁定好段 + 局部重渲 + 分段内容哈希复用**：优先用 `--start-frame / --end-frame` 只重渲改动区间（若只换背景/后处理且使用 `Layer-Decoupled` 管线，甚至可跳过 3D 重渲），配合 BeatScope `render.mjs --reuse-unchanged` 秒级无损复用未变分段。
- **每次只改 2～4 个具体硬伤**：必须把用户抽象的“感觉不对”翻译成精确时间段、文件与参数级改法。
- **先出对照图 / 新探针图再全量渲染**：遇到审美方向分叉（如滤镜调性、异变材质质感），先在几秒内生成 2～4 格对照图让用户拍板，改完后出新版本 `probe_grid_v2.png`（不覆盖旧文件）确认过关，再渲全片。
- **同步记录到 BeatScope `creative-review.json` 的 `repairs[]`**：
  ```json
  {
    "id": "patch-1",
    "before_preview_sha256": "<旧预览片 SHA-256>",
    "locked_intervals": [[20.5, 28.0]],
    "target_intervals": [[12.8, 16.5], [34.3, 38.4]],
    "changes": [
      "hellscape_renderer.py: 锁死蓝天底板像素与色温，仅云朵遮罩内原地替换为日照血肉云",
      "hellscape_renderer.py: 取消蓝天段落的暗角压黑滤镜，消除 180 BPM 切换时的明度断崖"
    ],
    "probe_grid_path": "probe-grid-v2.png",
    "probe_grid_sha256": "<新探针图 SHA-256>"
  }
  ```

---

## 三、 标准输出格式
导演审片后，先用简短人话给出：
1. **锁死的高光段**（秒数与帧号）；
2. **扣分的 2～4 个硬伤**（点明多样性 / 明度曝光 / 接缝 / 音画哪个维度出问题）；
3. 直接附上按 `prompts/surgical_patch_template.md` 填好的**一键复制外科手术修改单**。

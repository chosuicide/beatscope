# 01｜导演拆片法：视觉基因剥离与 BeatScope 时序映射

无论用户上传参考视频（1 条或多条），还是只给文字创意，导演 LLM 都必须完成以下两步：**提炼底层视觉语法（绝不照抄表面物件）** + **映射到 BeatScope 权威音乐事实（绝不硬编码时间轴）**。

---

## 一、 有参考视频时的强制剥离清单（绝对不可带入新方案）
- 原片出现的具体摄影对象、角色与地标（特定街道、特定花卉、标志性建筑物、原片 3D 物件等）。
- 原片中的任何具体文字、标语、UI 文案。
- 原片专属的标志性配色组合（避免退化成 1:1 换皮模仿）。
- 原参考视频自带的原曲剪辑时间点（绝不可把参考片的切点直接套在目标歌曲上）。

---

## 二、 必须提炼的 5 项通用底层视觉语法（风格中立）
不论参考片或目标风格是极简、梦幻、日系平面、赛博、绘卷还是暗房，都按以下 5 个维度拆解：

1. **明暗曝光与留白骨架（Luminance & Negative Space）**
   - 整体是高调通透（大面积浅色/晴空/纸白）、中调胶片、还是低调暗场主控？
   - 主体与留白比例是多少？（例如 70% 克制留白 + 30% 焦点主体，或满屏压迫构图）
   - 若存在跨世界切换（如表里翻转），**明度是否连贯**，还是刻意制造黑场断层？
2. **时间轴与帧率节奏（Temporal Cadence）**
   - 60fps 丝滑流动、24fps 电影呼吸感、还是抽帧阶梯（如 6fps/12fps）与双时钟拉扯？
   - 整段情绪弧线如何演进？（例如：克制定场 → 局部试探/预告闪帧 → 多景别爆发高潮 → 呼吸留白 → 收束定格）
3. **视觉变化与转场物理（Transition & Mutation Physics）**
   - 画面靠什么推动变化？例如：
     - 机位推进 / 径向甩镜 / 景深焦段变化；
     - 景深分层像素拉伸 / 光学折反射 / 粒子解体重组；
     - **同背景原位局部异变**（背景像素与曝光锁死不动，仅云层/物体/材质原地变异）；
     - 跨媒介切换（实拍 ↔ 版画半调 ↔ 排版分栏 ↔ 3D 雕塑）。
4. **材质与光影统一机制（Cohesion & Medium）**
   - 前景与背景如何避免“两张皮贴纸感”？（例如统一环境反射球、大气散射边缘包裹、统一色域 LUT、统一胶片/和纸颗粒层、或刻意零羽化刀切。）
5. **收束与留尾方式（Resolution Grammar）**
   - 子弹时间零重力定格、一帧硬切冷漠归位、阶梯光圈闭死、还是柔和淡出留白？

---

## 三、 将视觉语法映射到 BeatScope 测量事实（严禁硬编码帧号）

通过 `node query.mjs [start end] --stages --accents --limit 16` 读懂目标歌曲后，按以下规则建立映射（**克制呼吸，不要把每个事件都变成全屏抽搐**）：

| 视觉语法维度 | 对应的 BeatScope 权威字段（`frame-timeline.json`） | 正确用法 | 禁止的反模式 |
| --- | --- | --- | --- |
| **大段落弧线**（开场 / 蓄力 / 爆发 / 过渡 / 收束） | `stages[]`（来自 `edit-plan.json`）与 `stagePhase`、`structure.family` | 将音乐段落边界绑定到不同的视觉形态、景别与空间场景；重复出现的 `family` 可做“回归但带变奏” | 写死“第 0~47 帧开场、48~95 帧高潮”；或脱离听感强行脑补结构 |
| **重拍硬切 / 局部异变 / 冲击触发** | `cueHits[]`（含 `strength` / `manual` / `isAccent`）与 `beatIndex` | 仅对筛选后的强重音、手动卡点或有设计的节拍周期触发切换、异变或闪帧预告 | 每个微小 onset 都切全屏；或仍触发已被用户删除的旧 `sourceTime` |
| **律动周期 / 阶梯时钟 / 呼吸感** | `beatPhase`、`barPhase` 与 `frame // step_divisor` | 驱动阶梯抽帧、周期律动、呼吸缩放或有节奏的镜头甩动 | 无视节拍的匀速滑动，或违背风格的无脑 `easeInOut` 弹窗 |
| **能量与质感调制** | `bands.low / mid / high / all`（经 `causal_attack_release_envelope` 平滑） | 在目标段落温和调制光影强度、颗粒、景深拉丝幅度或材质反射能量，稳态段保持克制 | 把未平滑的原始逐帧频段直接乘进 3D 顶点/缩放造成 15–30Hz 机械抖动 |
| **镜头构图与复用** | 可选 `score.json` 编译后的 `frame.score.{viewId, setup, sinceCut, values}` | 用 BeatScope `edit-score.js` 管理可复用机位与回访时钟，渲染端只消费编译结果 | 在渲染脚本里另写一套和 `score.json` 打架的切点表 |

# Handoff appendix

Read AGENT.md first. This appendix is needed only when project identity,
authorization or cached evidence is uncertain.

## Match the project
Match the original audio SHA-256 in rhythm-map.json, score duration and the
saved project/revision record. An asset directory alone does not identify a
song or prove an accepted project. Reuse code/assets independently of another
song's timing. Read supplied inputs and explicitly linked records; do not scan
the whole machine for history or assets. When linked records disagree, recover
the matching record if possible. Ask about the intended work only if unresolved;
do not ask users to resolve internal cache versions.

## Direction and assets
References and assets are optional. Reuse the user's accepted direction and
source authorization. Without a reference, make independent authored choices.
Without assets, procedural visuals are available; online selection requires
authorization. Ask only for a blocking input, combining direction and sourcing
in one ordinary-language question when both are missing. Do not manufacture
accepted requirements from paths or flags. Preserve credits and usage conditions.
custom-media.json, when present, records authored arrangement and SHA references;
its original/proxy media bytes remain in the separate project assets directory.

## Reuse checks
Cache the probe by all package member hashes, queries by rhythm/edit-plan hashes,
and renders by source/score/assets/audio/settings hashes. Changed inputs invalidate
affected evidence. Keep observations, output and job score outside this ZIP.
Reuse reference observations and unaffected previews instead of repeated full
passes. Runtime validity, self-review and user acceptance are separate states.
Respect requested analysis/rendering limits. See BEATSCOPE.md for timing invariants.

## Reference review
Review representative continuous passages with audio and consecutive source frames
for dense motion. Slow playback to inspect anticipation, arrival, layer speeds and
what survives the handoff; avoid inferring filmed motion from isolated stills.
Record observations once. Compare paired moving passages after relevant revisions.
If repeated checks fail, change approach or report the remaining limitation.
